# 💳 Sistema de Conta Bancária – Java (DDD)

## 📌 Descrição

Projeto desenvolvido para simular operações bancárias utilizando Programação Orientada a Objetos e organização baseada nos princípios de Domain-Driven Design (DDD).

O sistema permite realizar operações como saque, pagamento e transferência, aplicando regras de negócio e separação de responsabilidades em camadas.

---

## 🎯 Objetivo

- Aplicar os pilares da POO (Encapsulamento, Herança, Polimorfismo e Abstração)
- Simular regras reais de negócio bancário
- Estruturar o projeto com base em DDD
- Organizar código em camadas (domínio, aplicação)

---

## 🛠️ Tecnologias Utilizadas

- Java
- Programação Orientada a Objetos
- Estrutura em camadas (DDD)
- Git e GitHub

---

## 🧠 Conceitos Aplicados

### 🔐 Encapsulamento
- Atributos privados
- Validação interna de saldo
- Controle de acesso via métodos públicos

### 🧩 Abstração
- Modelagem da entidade Conta
- Separação entre regra de negócio e execução

### 🔄 Polimorfismo 
- Sobrescrita de métodos
- Especialização de tipos de conta (ex: ContaCorrente, ContaPoupanca)

### 🧱 Domain-Driven Design (DDD)
- Camada de Domínio contendo entidades e regras de negócio
- Camada de Aplicação responsável pela execução
- Separação clara de responsabilidades

---

## ⚙️ Funcionalidades

- Criar conta bancária
- Consultar saldo
- Realizar saque (com validação de saldo)
- Realizar pagamento
- Transferência entre contas
- Validação de operações inválidas

---


## 💡 Regras de Negócio Implementadas

- Não permite saque com saldo insuficiente
- Não permite transferências com valor negativo
- Atualização automática de saldo após operações
- Validação básica de entradas
